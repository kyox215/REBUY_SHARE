# V1 实施路线与验证计划

文档状态：Owner 里程碑与验证合同  
当前门：仅 P1 本地客户端视觉原型已获准；其余阶段仍需各自 Owner Gate。  
验证原则：按风险匹配最小验证；全量测试、完整构建和 E2E 只在确实覆盖新增风险的里程碑或发布候选执行，不在每个小阶段重复。

## 1. 验证等级

| 风险 | 最小验证 | 额外门槛 |
|---|---|---|
| 低：文档、文案、局部静态内容 | 局部验证：文件存在、链接、标题、围栏、目标页面检查 | 无需全量测试 |
| 中：共享组件、权限合同、跨页面交互 | 综合验证：受影响测试、类型/构建、关键浏览器路径 | 一次综合审查 |
| 高：生产、数据库、支付、隐私、迁移、跨租户写入 | 专项验证：专项审查、负向测试、回滚证据、监控/备份检查 | Owner 明确批准后才可推进 |

每个阶段都保留范围、证据、Owner 决定和回退点。实现代理不得把本地演示、静态检查或合成数据描述成生产验收。

独立审查触发器：凡涉及数据库/schema/RLS、身份与权限、支付、隐私、生产写入或跨组织数据的阶段，必须由独立审查完成并保留结论、负向证据和回退证据；P1 文档和本地视觉原型不连接这些系统，也不因此提前启动高风险审查。

## 2. 分阶段路线

### P0 文档基线

| 项目 | 内容 |
|---|---|
| 范围 | 完成 README、00–06；统一多商家 V1、角色、架构、阶段和 P1 原型合同 |
| 依赖 | 当前批准的产品决定、01/02 设计基线 |
| 风险等级与主要风险 | 低：历史较窄方案或旧原型重新成为隐含范围 |
| 最小验证 | 00–06 七个文档存在且非空；README 的七个相对链接可解析；标题和要求章节存在；围栏成对；反向微信功能表述和真实 PII 检查 |
| Owner Gate | Owner 确认文档是后续执行入口，冲突按当前决定处理 |
| 回退方式 | 只修订本轮新增文档或记录决定；保留既有 01/02，不回退无关修改 |

### P1 本地客户端视觉原型

| 项目 | 内容 |
|---|---|
| 范围 | 移动优先、桌面响应式的首页、分类/搜索、详情、购物车/结算、订单、我的；演示五项导航、搜索筛选、游客/零售/批发样本、普通/二手差异、多商家批次/子订单、深色和三语 |
| 依赖 | 01、02、06；虚构商品/商家/订单和可识别视觉资产 |
| 风险等级与主要风险 | 中：原型被误认为生产功能；身份样本被误认为手动价格切换；信息溢出或二手事实缺失 |
| 最小验证 | 相关 lint/typecheck/build；移动和桌面页面检查；关键点击路径；无重叠/溢出；控制台无阻塞错误 |
| Owner Gate | 先达到 06 的首个有效预览门槛；只有达到门槛，才打开 Codex 侧边栏预览 |
| 回退方式 | 保留文档和虚构数据合同，停止或回退本地原型改动；不触及后端、数据库或生产 |

### P2 登录/组织/权限纵切

| 项目 | 内容 |
|---|---|
| 范围 | 认证、组织、成员、角色、店铺范围、批发资格和服务端授权的最小闭环 |
| 依赖 | P0；04 数据边界；03 权限矩阵；P1 仅提供交互参考 |
| 风险等级与主要风险 | 高：跨组织读取、客户端伪造角色、RLS 与服务端授权不一致 |
| 最小验证 | 角色正向/负向授权、RLS 隔离、DTO 脱敏、会话失效、审计和类型/相关构建 |
| Owner Gate | 通过安全/权限专项审查，确认没有浏览器 service role 和跨租户泄露 |
| 回退方式 | 禁用未通过的组织/角色路径，恢复上一个迁移和策略快照；不绕过授权继续开放 |

### P3 商家入驻与平台审核

| 项目 | 内容 |
|---|---|
| 范围 | 入驻申请、补件、审核、通过/拒绝/暂停、店铺建立和审核记录 |
| 依赖 | P2 身份和权限；审核资料、政策和 SLA 决策 |
| 风险等级与主要风险 | 高：资料过度收集、审核越权、审批状态丢失或商家被错误启用 |
| 最小验证 | 状态迁移、重复提交、私有资料访问、审核角色负向测试、审计和回滚演练 |
| Owner Gate | Owner 确认资料、责任、时限和法律/隐私处理；高风险资料需专项审查 |
| 回退方式 | 停止新申请或店铺启用，保留只读审核记录，恢复最近可验证状态 |

### P4 商品/定价/库存

| 项目 | 内容 |
|---|---|
| 范围 | 分类、商品、变体、listing、零售/批发价、起订量、阶梯价、普通数量库存和二手单件库存 |
| 依赖 | P2 权限、P3 有效商家；价格和库存业务决策 |
| 风险等级与主要风险 | 高：批发价泄露、超卖、单件重复售出、并发更新覆盖和商业数据暴露 |
| 最小验证 | 角色价格矩阵、库存并发/预留、二手单件唯一性、状态迁移、RLS、审计和受影响模块构建 |
| Owner Gate | 数据库/RLS/库存专项审查通过；没有安全证据不得进入真实库存 |
| 回退方式 | 下架问题 listing，冻结受影响库存写入，按审计事件和版本恢复；不直接删除历史记录 |

### P5 浏览/购物车/订单

| 项目 | 内容 |
|---|---|
| 范围 | 浏览、搜索、详情、身份适用价格、多商家购物车、结算校验、批次、商家子订单和订单事件 |
| 依赖 | P2 身份；P4 目录/价格/库存；地址和订单部分失败策略 |
| 风险等级与主要风险 | 高：重复订单、价格/库存变化、批次拆分错误、部分成功状态不清 |
| 最小验证 | 关键浏览器路径、幂等重试、并发库存、批次/子订单关系、失败恢复、订单权限和相关构建 |
| Owner Gate | 订单和库存专项审查；明确不能在线支付或自动退款的边界 |
| 回退方式 | 停止提交入口或切换只读查询，按请求标识查询原结果；不通过重试创建第二单 |

### P6 商家后台闭环

| 项目 | 内容 |
|---|---|
| 范围 | 商家紧凑工作台、商品/价格/库存操作、子订单处理、售后响应和商家日志 |
| 依赖 | P2–P5；商家操作职责、字段可见性和售后政策 |
| 风险等级与主要风险 | 高：商家员工越权、内部商业字段泄露、运营操作不可追溯 |
| 最小验证 | Owner/员工权限矩阵、字段级 DTO、关键状态和审计、桌面密度/键盘路径、相关测试 |
| Owner Gate | 商家业务代表和安全审查确认可操作范围；后台视觉不与买家端混淆 |
| 回退方式 | 按模块关闭写入或回到只读工作台，保留订单和库存事件，逐项恢复 |

### P7 受控试运营

| 项目 | 内容 |
|---|---|
| 范围 | 小范围、明确商家和客户、受控数据、监控、客服和回滚流程的试运营 |
| 依赖 | P2–P6 全部通过；生产环境、备份、隐私、运维和支持流程 |
| 风险等级与主要风险 | 高：真实 PII、跨租户事故、库存/订单损失、监控缺失和无法回滚 |
| 最小验证 | 发布候选完整构建/lint/typecheck/E2E、RLS 负向测试、备份恢复、监控告警、试运营演练 |
| Owner Gate | 生产、数据库、隐私、运营和安全专项审查均通过，Owner 书面批准 |
| 回退方式 | 使用已验证版本回滚，暂停写入/试运营，按事件和备份恢复；保留审计证据 |

### P8 后期支付/物流/税务

| 项目 | 内容 |
|---|---|
| 范围 | 在线支付与平台分账、退款、物流自动化、税务/电子发票等后期能力 |
| 依赖 | P7 的真实订单和责任边界；商业、法律、税务、隐私、安全和供应商决策 |
| 风险等级与主要风险 | 高：资金损失、分账错误、税务不合规、个人资料扩散和供应商故障 |
| 最小验证 | 独立支付/税务/隐私/安全专项审查、沙箱和故障演练、对账、回滚与人工兜底 |
| Owner Gate | 未完成全部专项审查不得进入 V1 生产范围 |
| 回退方式 | 关闭新支付/物流入口，保留人工处理和可核对订单，不删除交易记录 |

## 3. 当前执行状态

- P0 文档基线正在本轮完成。
- P1 已获准，但只有达到首个有效预览门槛后才打开 Codex 侧边栏；门槛见 [本地视觉原型执行合同](./06-本地视觉原型执行合同.md)。
- P2–P8 不因 P1 的静态或本地预览证据自动打开。
- 本轮不启动独立审查、不做哈希检查、不连接数据库、不部署；生产、数据库、支付和隐私风险在相应阶段必须专项审查。
