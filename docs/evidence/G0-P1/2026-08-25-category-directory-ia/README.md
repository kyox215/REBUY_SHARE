## 1. 范围与 Owner 决定

本批响应 Owner 原话：然后网站整体的目录结构应该是跟淘宝类似，首页显示推荐内容，然后分类展示各个种类的列表，点进去后才是商品。这里只借鉴层级，不复制淘宝品牌、配色、拥挤营销或视觉。
