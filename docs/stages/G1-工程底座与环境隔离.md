## 10. 最小 CI 与 Preview 回退门

本节是 G1 目标合同，不代表 CI 已创建：

1. CI 使用 Node 22 和 pnpm `10.33.3`，安装策略与 `prototype/pnpm-lock.yaml` 一致。
2. 定向门至少运行 `pnpm typecheck`、`pnpm lint`、`pnpm build`；失败不得生成可晋级 Preview 的成功标记。
3. CI 输出只保留必要构建/检查摘要，禁止打印 env 值、secret、个人路径中的敏感信息或 `.env` 内容。
4. Preview 只能由已通过 CI 的可追溯 ref 生成；记录部署 ref、时间、负责人、健康检查和可回退版本。
5. 回退演练至少验证：停止错误 Preview 入口、切换到上一可验证 ref、恢复访问边界、保留失败日志摘要且不复制凭据。
6. CI/Preview 通过不等于 G1 Owner Gate 通过，也不等于 Staging/Production 通过。
