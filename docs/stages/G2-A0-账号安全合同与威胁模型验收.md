- 结论：本记录只使用最小化文档摘要；规划证据不能替代独立安全审查或 Auth/安全运行证据。

### 8.1 未来独立资源授权 Gate（不属于七项政策决定）

non-production project/resource、cost、secret、OAuth、SMTP 和任何连接必须另行取得独立资源授权。该 Gate 不属于上述七项政策决定，不属于 G2-A0 Exit 条件，也不会因 A0 签署而获批；A0 Exit 至多打开 G2-A1 准备门。当前 A0 不授权创建项目、产生费用、配置 secret 或连接任何环境。

### 8.2 已确定、不重复询问

- 支持多店铺；店铺 scope 必须通过有效 membership 和服务端上下文校验。
- 批发价格、起订量和阶梯价由有效批发资格、组织状态、商品规则和服务端实时判断自动决定；不提供手动切换零售/批发模式的开关。
- `wholesale application` 与 `wholesale qualification` 分离；申请历史不可变，当前资格独立管理。
- identity、membership、authorization、verification 四层分离；登录成功不自动获得组织、平台角色或批发资格。
- 浏览器不得持有 service role；publishable key 不是授权边界。
