## 1. 使用规则

执行路线见 [全局执行总计划](./14-全局执行总计划.md)，阶段事实见 [阶段记录索引](./stages/README.md)，README 只做导航。任何其他文档中的“当前状态”都是说明性摘要；需要更新状态时先改本台账，再按需要同步 README/阶段记录，避免形成第二份每日状态源。

阶段状态只能使用以下枚举：

| 状态 | 含义 |
|---|---|
| 未开始 | 已有规划或依赖，但本阶段尚未执行 |
| 准备中 | 前置条件/环境/人员正在准备，尚未进入阶段性实现或验证 |
| 执行中 | 本阶段已有授权工作正在进行，阶段 Exit/全部 Gate 尚未完成 |
| 待 Owner 验收 | 阶段产物和最小证据已形成，等待 Owner 全部验收；不等于已通过 |
| 已通过 | Owner Gate 已明确通过，并有可追溯决定记录 |
| 已阻塞 | 依赖或明确风险使阶段不能继续，已记录阻塞原因和解除条件 |
| 已取消 | Owner 明确取消，不再按原路线继续 |

证据级别只能使用以下枚举：

| 证据级别 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 规划 | 范围、合同、依赖、假设或设计意图 | 代码、环境、真实数据或生产能力 |
| 本地静态 | 文件、类型、lint、构建、链接或静态检查在本地成立 | 真实用户、权限、网络、部署或生产 |
| 本地交互 | 本地原型/应用在指定视口和合成数据下可见、可点击 | 真实认证、数据库、RLS、订单写入或生产验收 |
| 独立测试 | 隔离测试环境中的受控功能和负向证据 | Staging、受控生产或生产数据 |
| Staging | 经隔离的预发布环境验证 | 生产流量、真实业务批准或长期运维 |
| 受控生产 | 有明确范围、监控、回滚和书面批准的生产试运营 | 全量生产完成或风险自动解除 |
| 生产 | 生产系统在对应 Owner/专项门下正式验收 | 不代表其他阶段自动通过 |
